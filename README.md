# RoomSketch

引っ越し前に、部屋の形と寸法・家具の大きさを入力して、平面図上で配置を検討する Android アプリです。

## できること（Phase1）

- **間取り**：矩形・L字・辺を順に入力して部屋を作成（閉合誤差の表示と按分補正）。開き戸・引き戸・窓・収納扉・柱・コンセント・エアコンを壁に配置。部屋をドラッグして住戸全体に並べる（壁に吸着）
- **家具**：幅・奥行・高さ、前面/背面に必要な空き、分解後寸法、状態（持参／購入候補／処分予定）。プリセットあり
- **配置**：ドラッグ・回転・壁への吸着・数値指定。重なり、部屋からのはみ出し、柱、ドアの開閉範囲、収納扉前、必要な空きの不足を自動判定。選択中の家具から壁・家具までの距離を表示。複数の配置案（A案・B案…）
- **搬入**：玄関・エレベーター・廊下などの開口に家具が通るかの目安判定、部屋ごとの搬入リスト共有
- **共有**：編集データ（JSON）を家族に送る／受け取ったファイルを読み込む（同じプロジェクトは上書き）、配置図を PNG で送る

## インストール

`main` に push すると GitHub Actions がビルドし、[Releases の「最新ビルド」](../../releases/tag/latest) に `RoomSketch.apk` を置きます。スマホでダウンロードしてインストールしてください。署名鍵を固定しているため、上書き更新できます。

## メモ

- 寸法はすべて mm で保持し、cm で表示します。面積の畳換算は 1畳＝1.62㎡ です
- データは端末内（アプリ専用領域）に JSON で保存します
